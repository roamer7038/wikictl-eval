# wikictl-eval

[日本語](README.ja.md)

Tasks, harness and graders that measure how much [wikictl](https://github.com/roamer7038/wikictl) changes the quality, cost and speed of an agent's work. The purpose and the decisions the results feed are in [roamer7038/wikictl#184](https://github.com/roamer7038/wikictl/issues/184).

## Conditions

| Condition | Access to the wiki |
|---|---|
| B0 | no wiki |
| B1 | a clone of the wiki, read and written with `rg`, `cat` and `git` |
| B2 | wikictl and [wikictl-claude-plugin](https://github.com/roamer7038/wikictl-claude-plugin) |

The prompt is the same under every condition except for its environment section ([`tasks/env-B0.md`](tasks/env-B0.md) and the others).

## Tasks

The prompts are in Japanese.

| ID | Task | Conditions | Answers |
|---|---|---|---|
| T1 | Recall values: answer 10 questions from a wiki of 72 pages and configuration files (`infra/`); for 6 of them an old value remains in meeting notes and history | B0 B1 B2 | current values of the generated world |
| T2 | Continue in another session: compute layered deploy values for 4 projects in session 1 and for all 8 projects (24 services) in session 2, which keeps neither the conversation nor the working directory | B0 B1 B2 | values computed by the layering rules |
| T3 | Write at the same time: three agents each create 5 incident pages and add rows to the same index page at once | B1 B2 | 15 pages and rows |
| T4 | Large wiki: the questions of T1 on a wiki of 1,012 pages | B1 B2 | as T1 |

All material is generated by [`gen/`](gen/) from a fixed seed; no private wiki is used.

## Measures

- Quality: T1/T4 count correct, stale, unknown and wrong answers; T2 counts correct fields; T3 counts missing pages and rows, duplicated rows, lost existing rows and the row order. Written pages are checked with `lint` of wikictl v0.4.1.
- Cost: USD from the token counts in `modelUsage` of the `result` event of `claude -p`, at the prices in [`grade/prices.json`](grade/prices.json).
- Speed: wall time and turns of a session, and the calls to `wikictl`, `git` and `rg` with the size of their output, logged by wrappers.

## Environment

- Versions: wikictl v0.4.1 (release binary verified against its checksum), plugin b5763e8, Claude Code 2.1.273; the values used are recorded in `build/versions.tsv`.
- Each session runs `claude -p` with its own HOME, `CLAUDE_CONFIG_DIR` and PATH, so the user's CLAUDE.md, memory, plugins and MCP servers are not loaded. Only B2 loads the plugin, with `--plugin-dir`. The built-in skills are the same under every condition.
- Tools: Bash, Read, Write, Edit, Glob and Grep (and Skill under B2). Subagents and web tools are not available.
- The wiki remote is a local bare repository, so the time includes no fetch over a network.
- Commands are logged by wrappers on PATH with their parent processes, so that the git that Claude Code runs itself is not counted as a call by the agent. Read, Grep and Glob are not logged by the wrappers; they are counted from the transcript as tool calls.
- Sessions are not sandboxed; the prompt only tells the agent not to read outside its working directory.

## Reproduce

Requires Linux, Python 3.12, git, ripgrep, jq, curl and Claude Code.

```sh
./setup.sh                                   # wikictl and the plugin in build/, material in data/
claude setup-token                           # save the token it prints to the file below
mkdir -p ~/.config/wikictl-eval && ( umask 077; cat > ~/.config/wikictl-eval/oauth-token )

harness/run.py --task T1 --cond B2 --model sonnet --rep 1           # one group
harness/batch.py --models opus,sonnet,haiku --reps 3                # every task and condition
grade/grade.py ../wikictl-eval-runs/*-r[123] > results/raw/main.jsonl
grade/report.py results/raw/main.jsonl > results/main.md
```

Groups are written to `../wikictl-eval-runs/` (or `$EVAL_RUNS`), outside any Git repository, because Claude Code puts the git status of an enclosing repository into the system prompt. The directory keeps the transcripts, and the environment of the agents holds the authentication token, so do not publish it.
