# モデルごとの成功 1 回あたりの費用と、上位のモデルが安くなる条件

[main.md](main.md) の本番（423 グループ）から [`grade/models.py`](../grade/models.py) で集計した。USD は公開の単価での換算。1〜5 節は、P3K の問題文の 2 通りの読み方をどちらも正答とした採点による（6 節を参照）。

## 用語

- p: 成功率（全問正答、規則違反なし）。c: 1 回の試行の平均 USD。
- 成功 1 回あたりの期待 USD = c / p。成功するまで試行を繰り返すときの平均の費用。p = 0 は ∞。
- 上位のモデル s が下位のモデル w より成功 1 回あたり安くなるのは、p_w / p_s < c_w / c_s のとき。つまり、下位のモデルの費用が上位の何割かを表す c_w / c_s が、下位のモデルが使える成功率の比の上限になる。

## 7. 問題文の解釈による違い（P3K・P7）
